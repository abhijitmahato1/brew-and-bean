# ☕ Brew & Bean

A modern, responsive café website built as a freelance-style frontend project.

## 🌟 Features

- Responsive design for desktop, tablet and mobile
- Mobile navigation menu
- Interactive Coffee, Breakfast and Desserts menu
- Café image gallery
- Why Choose Us section
- Customer reviews
- Table reservation form
- Form validation
- Scroll reveal animations
- Back-to-top button
- Smooth scrolling
- Navbar scroll effect

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Font Awesome

## 📱 Responsive Design

The website is designed for:

- Desktop
- Tablet
- Mobile

## 🎯 Project Purpose

This project was created as a portfolio project to demonstrate
frontend web development, responsive design and JavaScript
interaction skills.
