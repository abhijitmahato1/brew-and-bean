# ☕ Brew & Bean

A modern, responsive café website built as a freelance-style frontend project.

## 🌟 Features

- Responsive design for desktop, tablet and mobile
- Mobile navigation menu
- Interactive coffee, breakfast and dessert menu
- Café image gallery
- Why Choose Us section
- Customer reviews
- Table reservation form
- Form validation
- Scroll reveal animations
- Back-to-top button
- Smooth scrolling
- Navbar scroll effect

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Font Awesome

## 📱 Responsive Design

The website is designed to work across:

- Desktop
- Tablet
- Mobile

## 🚀 Project Purpose

This project was created as a portfolio piece to demonstrate frontend web development and responsive UI design skills.
